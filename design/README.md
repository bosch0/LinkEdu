# Design

Todo el diseño UI/UX de la app, hecho con Claude Design.

- `claude-design/`: lo que genera Claude Design (pantallas, prototipos, exportaciones).
- `assets/`: logo, iconos e imágenes finales que usa la app. Lo que está aquí es lo que `web_app/` puede coger.

El diseño aprobado se pasa a `web_app/`. Si algo cambia del diseño, se anota en el diario.
