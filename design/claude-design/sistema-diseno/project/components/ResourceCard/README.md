# ResourceCard

Tarjeta de un recurso compartido (unidad didáctica, presentación, vídeo, rúbrica).

- Arriba, el tipo y la extensión en `kicker` mono: "PDF · 18 págs".
- El título describe el contenido, no el archivo: "Funciones lineales con datos reales", no "tema4_final.pdf".
- La primera etiqueta es la materia (`pizarra`); las siguientes, la etapa (`cuaderno`).
- Abajo, descargas y guardados con cifras tabulares y formato español.
- "Guardar" es `quiet` y cambia a "Guardado". Quien lo usa guarda el estado en `saved`.
