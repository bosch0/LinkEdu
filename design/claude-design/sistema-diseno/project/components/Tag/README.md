# Tag

Etiqueta corta para clasificar docentes, recursos y proyectos.

- `pizarra`: materia o especialidad ("Matemáticas", "Desarrollo Web").
- `cuaderno`: etapa educativa ("Primaria", "3º ESO", "FP Grado Superior").
- `subrayador`: un estado que hay que ver de un vistazo ("Disponible", "Nuevo"). Uno por tarjeta como mucho.
- `neutral`: el resto (metodologías, idiomas).

Máximo tres etiquetas por tarjeta más la de estado. Texto de una a tres palabras.
