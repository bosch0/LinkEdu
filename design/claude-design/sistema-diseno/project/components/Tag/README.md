# Tag

Etiqueta corta para clasificar docentes, recursos y proyectos.

- `marino`: materia o especialidad ("Matemáticas", "Desarrollo Web").
- `azul`: etapa educativa ("Primaria", "3º ESO", "FP Grado Superior").
- `turquesa`: "Disponible", para proyectos o para ser contratado.
- `naranja`: lo nuevo o destacado ("Nuevo", "Plazo abierto"). Uno por tarjeta como mucho.
- `neutral`: el resto (metodologías, idiomas).

Máximo tres etiquetas por tarjeta más la de estado. Texto de una a tres palabras.
