# EmptyState

Lo que se ve cuando una lista está vacía: sin proyectos, sin conexiones, sin resultados.

- Lleva la ilustración del sistema: formas planas del logo (pizarra marino, sol naranja, píldora turquesa) sobre un fondo `surface-sunken`.
- El título dice qué falta y la palabra clave lleva `le-subrayado`.
- El texto explica en una frase cómo llenar el hueco.
- Una sola acción `primary` que resuelve el vacío ("Crear proyecto", "Buscar docentes").
