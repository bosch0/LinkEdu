# Icon

Los 26 iconos de LinkEdu, de trazo 2px con extremos redondeados, en una rejilla de 24px.

- Toman el color del texto (`currentColor`): ponlos dentro del elemento que les da color.
- Tamaños: 16px en metadatos, 20px junto a texto `body` (por defecto) y 24px sueltos.
- Un icono solo, sin texto, necesita `label` para el lector de pantalla. Junto a texto, no.
- Los SVG sueltos están en `design/assets/iconos/` del repo. Para añadir uno, edita `iconos.py` y ejecútalo: actualiza los archivos y este componente a la vez.

Nombres: inicio, buscar, red, conectar, perfil, mensajes, notificaciones, proyecto, recurso, empleo, formacion, guardar, compartir, megusta, comentar, calendario, ubicacion, descargar, subir, filtro, ajustes, mas, cerrar, check, flecha, menu.
