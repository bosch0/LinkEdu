# Avatar

Foto o iniciales de un docente, un centro o una empresa.

- Sin foto, muestra dos iniciales. El color sale del nombre, así que la misma persona siempre tiene el mismo color.
- `available` añade el anillo `turquesa`: la persona está abierta a proyectos o a ser contratada. Lo anuncia también al lector de pantalla.
- Tamaños: `s` (32px) en listas y autoría, `m` (48px) en el feed, `l` (72px) en tarjetas de perfil.

Quien lo usa pasa el nombre completo; la foto (`src`) es opcional.
