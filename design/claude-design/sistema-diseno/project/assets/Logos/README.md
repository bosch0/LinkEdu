# Logos

Logo de LinkEdu en cuatro versiones (horizontal, vertical, icono y texto) y tres colores. La versión sin sufijo es la de color, para fondos claros. `-azul` va a una tinta en azul marino `#073157`, también para fondos claros. `-blanco` va a una tinta en blanco, para fondos oscuros: paneles `marino` y fotos. Los originales están en `design/assets/logo/` del repositorio.
