# Iconos

Los 26 iconos de LinkEdu en SVG, a 24px, con trazo de 2px y extremos redondeados. Toman el color del texto (`currentColor`).

No se editan a mano. Para añadir o cambiar un icono, edita `iconos.py` y ejecútalo desde la raíz del repo:

```
python design/assets/iconos/iconos.py
```

El script reescribe estos SVG y el componente `Icon` del sistema de diseño (`design/claude-design/sistema-diseno/project/components/bundle.js`).
