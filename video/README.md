# Vídeo

Vídeo final que muestra la app.

- Aquí van el guion, el guion gráfico y las notas.
- `motion/` es el proyecto de Remotion para hacer el vídeo con motion graphics
  (ver `motion/README.md`).
- Los archivos de vídeo pesados (`.mp4`, `.mov`...) **no se suben a git**
  (están ignorados en `.gitignore`). Guardadlos en OneDrive o Drive y anotad
  aquí el enlace.
- Hay que tener en cuenta que en la app hay botones para alternar entre las diferentes vista de profesor, alumno y empresa. No deben salir en el video.
